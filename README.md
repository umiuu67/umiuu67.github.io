# Umiuu 个人网页

这是一个托管在 GitHub Pages 上的纯静态个人网页。

## 地址

- 线上页面: <https://umiuu67.github.io/index.html>
- 仓库地址: <https://github.com/umiuu67/umiuu67.github.io>
- 本地源码目录: `D:\desktop\C\umiuu67.github.io`

## 页面结构

- `index.html`: 首页导航
- `memo.html`: 备忘录
- `schedule.html`: 课程表
- `calendar.html`: 日历
- `trash.html`: 垃圾桶
- `css/`: 全站样式
- `js/`: 增强脚本
- `assets/`: 图标和背景资源

## 编辑与发布

1. 修改本地文件，例如 `index.html` 或 `css/style.css`。
2. 提交更改:

```powershell
git add .
git commit -m "更新页面"
```

3. 推送到 GitHub:

```powershell
git push
```

推送后 GitHub Pages 会自动更新线上页面，通常等待一两分钟即可看到效果。
